# คู่มือสร้างเกมบิงโกของตัวเอง (หน้า “สร้างเกม”)

ลิงก์: `https://kunnaifoodanube.github.io/character-bingo/create.html`
(หรือกด **✨ สร้างเกมของฉัน** ในจอพิธีกร › เมนูอื่น ๆ)

## ใครใช้ได้
- ใครก็สร้างเกมได้ ต้องเข้าสู่ระบบด้วยบัญชี Google
- แก้ไข/ลบได้เฉพาะคนที่สร้างเกมนั้น (ผู้ดูแล dn14042522@gmail.com ลบหรือแก้เกมที่ไม่เหมาะสมได้)

## สร้างเกม
1. กด **+ สร้างเกมใหม่** แล้วตั้งชื่อเกม
2. แต่ละข้อมี 2 ส่วน
   - **โจทย์** ขึ้นบนจอใหญ่ให้ทั้งห้องดู ใส่รูป พิมพ์คำ หรือทั้งสองอย่าง
   - **คำตอบ** อยู่บนบัตรของผู้เล่น ใส่รูปหรือพิมพ์คำ
3. กด **+ เพิ่มข้อ** ทีละข้อ หรือ **🖼️ เพิ่มหลายรูปพร้อมกัน** แล้วเลือกว่ารูปเป็นโจทย์ / คำตอบ / ทั้งคู่
4. ต้องมีอย่างน้อย 24 ข้อ (สูงสุด 60) บัตรแต่ละใบสุ่มคำตอบมา 16 ช่อง
5. ระบบบันทึกอัตโนมัติ ดูสถานะ “✓ บันทึกแล้ว” มุมขวาบน

## เล่น
- **ดูตัวอย่างบัตร** — ดูหน้าตาบัตร 4×4
- **เผยแพร่เกม** — เกมขึ้นในรายชื่อเกมบนจอพิธีกรของทุกคน (ต้องครบทุกข้อ และคำตอบไม่ซ้ำกัน)
- **เปิดจอพิธีกร** — เปิดเล่นได้ทันที แม้ยังไม่เผยแพร่ แล้วให้ผู้เล่นสแกน “QR เข้าเกม”
- ค่าเริ่มต้น จอใหญ่แสดงเฉพาะโจทย์ ไม่เฉลยคำตอบ (มือถือก็ไม่บอกคำตอบ) · ถ้าอยากให้เห็นคำตอบด้วย ติ๊ก “แสดงคำตอบบนจอใหญ่ด้วย”
- ระบบสลับบัตร จับเวลาแตะ ตรวจบัตร พิมพ์บัตรสำรอง ใช้ได้เหมือนเกมอื่นทุกอย่าง
- อย่าแก้เกมระหว่างที่กำลังเล่น เพราะบัตรที่แจกไปแล้วจะไม่ตรงกับเกม

## ข้อมูลทางเทคนิค
- เก็บใน Firestore (แผนฟรี): `games/{gameId}` + `games/{gameId}/items/{itemId}`
- ภาพย่ออัตโนมัติเป็น WebP เก็บในฐานข้อมูล (โจทย์ ≤ 1024 px, คำตอบ ≤ 360 px) ไม่ใช้ Cloud Storage
- กฎความปลอดภัยอยู่ใน `firebase/firestore.rules` (ต้อง Publish ใน Firebase Console ทุกครั้งที่แก้)
- ต้องเปิดการล็อกอินด้วย Google ใน Firebase Console › Authentication › Sign-in method › Google และมี `kunnaifoodanube.github.io` ใน Authorized domains
- ทดสอบอัตโนมัติ: `python3 tests/e2e_creator.py . [โฟลเดอร์ภาพหน้าจอ]` (ฐานข้อมูลจำลอง)
