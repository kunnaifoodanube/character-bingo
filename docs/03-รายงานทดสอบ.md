## D. ข้อจำกัดของระบบ (ตามการออกแบบ)

1. **ไม่มีการซิงก์แบบเรียลไทม์ระหว่างพิธีกรกับผู้เล่น** มือถือผู้เล่นไม่รู้ว่าตัวไหนถูกเรียกแล้ว
   จึง**ไม่สามารถห้ามผู้เล่นแตะตัวที่ยังไม่ถูกเรียกได้** แต่การตรวจรางวัลจากหน้าพิธีกรจะปฏิเสธการแจ้งชนะผิดได้ 100%
2. ผู้เล่นที่ **ไม่เคยเปิดเว็บเลย** จะเปิดเกมไม่ได้ถ้าไม่มีอินเทอร์เน็ต ต้องใช้บัตรกระดาษ
3. บัตรเก็บอยู่ในมือถือเครื่องนั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์ เปิดโหมดไม่ระบุตัวตนแล้วปิดแท็บ หรือเปลี่ยนเครื่อง บัตรจะหาย
   (การล้างข้อมูลอัตโนมัติของ iPhone จะเกิดหลังไม่ได้เปิดเว็บหลายวัน จึงไม่กระทบเกมในวันเดียว)
4. ประวัติการสุ่มเก็บอยู่ในเครื่องพิธีกรเครื่องเดียว จึงควรดาวน์โหลด JSON สำรองไว้เป็นระยะ
5. ชุดภาพฉบับร่างในหน้าจัดการภาพอยู่เฉพาะเบราว์เซอร์ที่ใช้แก้ ต้องส่งออกและอัปโหลดขึ้น GitHub ผู้เล่นจึงจะเห็น
6. ระบบไม่รับประกันว่าจะไม่มีผู้ชนะพร้อมกัน (ดูสถิติในหัวข้อ B) และมีโอกาสประมาณ 5% ต่อเกมที่ผู้เล่น 2 คนได้เลขบัตรมือถือตรงกัน
7. ถ้าต้องการซิงก์แบบเรียลไทม์จริง ต้องใช้บริการภายนอก (เช่น Firebase แผนฟรี ซึ่งต้องสมัครบัญชีและมีโควตา) ต้นแบบนี้**ยังไม่ได้เพิ่ม** เพราะต้องได้รับอนุญาตก่อน
