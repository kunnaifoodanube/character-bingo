# Galactic Bingo — เวอร์ชันสติกเกอร์ SDM

- **หน้าพิธีกร:** https://kunnaifoodanube.github.io/character-bingo/galactic/host.html
- **หน้าผู้เล่น:** https://kunnaifoodanube.github.io/character-bingo/galactic/
- **เวอร์ชันต้นแบบ (Film & Animation) ยังอยู่ที่เดิม:** https://kunnaifoodanube.github.io/character-bingo/

## ภาพ
- สติกเกอร์ชุด "กาแลคติก" 33 ภาพ จาก Google Drive โฟลเดอร์ "สติกเกอร กาแลคติก" (Digital Arts SPU)
- ข้อ 32 ใช้ไฟล์ปรับปรุง `32_(1.2).png` (ไฟล์ `32.png` เดิมไม่ได้ใช้)
- ตัดขอบโปร่งใส จัดเป็นสี่เหลี่ยมจัตุรัส ย่อเป็น 600×600 WebP (`galactic/themes/galactic/g01–g33.webp`)
- ชื่อบนบัตรตั้งตามท่าทางของภาพ แก้ได้ในหน้าจัดการภาพ หรือใน `tools/build-galactic.py`

## แยกจากเวอร์ชันต้นแบบอย่างไร
- ข้อมูลในเครื่อง (บัตรผู้เล่น สถานะพิธีกร ฉบับร่าง) เก็บแยกด้วยคำนำหน้า `gx.` — เปิดสองเวอร์ชันในเครื่องเดียวกันได้ ไม่ทับกัน
- แคชออฟไลน์แยกเป็น `gx-…` / `cb-…` และแต่ละเวอร์ชันลบเฉพาะแคชของตัวเอง
- ห้องซิงก์ของพิธีกรสุ่มรหัสใหม่ต่อเครื่องอยู่แล้ว

## สร้างใหม่หลังแก้โค้ดเวอร์ชันหลัก
```
python3 tools/build-galactic.py <โฟลเดอร์ภาพ 1.png … 33.png, 32b.png>
```
