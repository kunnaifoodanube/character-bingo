## ภาพ
- สติกเกอร์ชุด "กาแลคติก" 33 ภาพ จาก Google Drive โฟลเดอร์ "สติกเกอร กาแลคติก" (Digital Arts SPU)
- ข้อ 32 ใช้ไฟล์ปรับปรุง `32_(1.2).png` (ไฟล์ `32.png` เดิมไม่ได้ใช้)
- ตัดขอบโปร่งใส จัดเป็นสี่เหลี่ยมจัตุรัส ย่อเป็น 600×600 WebP (`galactic/themes/galactic/g01–g33.webp`)
- ชื่อบนบัตรตั้งตามท่าทางของภาพ แก้ได้ในหน้าจัดการภาพ หรือใน `tools/build-galactic.py`

## เวอร์ชัน 1.6.0 (19 พ.ย. 2569) — อัปเดตโค้ด + หน้าตาใหม่
- ใช้โค้ดเกมรุ่นล่าสุดเท่ากับ Film & Animation v1.5.6 → มี **จับเวลาแตะ** (ค่าเริ่มต้น 5 วินาที) และ **สิทธิ์สลับบัตรคนละ 1 ครั้ง** แล้ว
- หน้าตาแนว **"คืนอวกาศ"**: พื้นน้ำเงินกรมท่ามีดาว ปุ่มเขียวมะนาว ช่องที่แตะเป็นสีส้มกุ้ง ช่องบัตรสีอ่อนให้สติกเกอร์เด่น จอหลักแสดงสติกเกอร์ในวงกลมสว่างเหมือนหน้าต่างยาน
- ฟอนต์ **Prompt** (ไทยไม่มีหัว ใช้ฟรี SIL OFL) เก็บไฟล์ไว้ในเว็บเอง เปิดออฟไลน์ได้
- หน้าพิมพ์บัตรสำรองยังเป็นพื้นขาว (ประหยัดหมึก) แต่ใช้ฟอนต์ Prompt
- ภาพ 33 ภาพและชื่อบนบัตรเหมือนเดิม · ลิงก์เดิม · เวอร์ชัน Film & Animation ไม่ถูกแก้
- สำรองของเดิม: branch `backup-before-galactic-v1.6` บน GitHub
- ไฟล์หน้าตาอยู่ที่ `tools/galactic-theme/` (galactic.css = สี, fonts.css + fonts/ = ฟอนต์)

## แยกจากเวอร์ชันต้นแบบอย่างไร
- ข้อมูลในเครื่อง (บัตรผู้เล่น สถานะพิธีกร ฉบับร่าง) เก็บแยกด้วยคำนำหน้า `gx.` — เปิดสองเวอร์ชันในเครื่องเดียวกันได้ ไม่ทับกัน
- แคชออฟไลน์แยกเป็น `gx-…` / `cb-…` และแต่ละเวอร์ชันลบเฉพาะแคชของตัวเอง
- ห้องซิงก์ของพิธีกรสุ่มรหัสใหม่ต่อเครื่องอยู่แล้ว

## สร้างใหม่หลังแก้โค้ดเวอร์ชันหลัก
```
python3 tools/build-galactic.py                 # อัปเดตโค้ด ใช้ภาพ/ชื่อเดิม (ใช้แบบนี้เป็นปกติ)
python3 tools/build-galactic.py <โฟลเดอร์ภาพ>    # สร้างภาพใหม่จากต้นฉบับ 1.png … 33.png, 32b.png
```
ก่อนรัน ให้เพิ่มเลข `GX_VERSION` ใน `tools/build-galactic.py` ทุกครั้ง (ล้างแคชเก่าในเครื่องผู้เล่น)
