# คู่มือเปลี่ยนภาพตัวละครด้วยตนเอง

ไม่ต้องแก้โค้ด ทำผ่านหน้า **จัดการภาพ** (`admin.html`) แล้วอัปโหลดไฟล์ขึ้น GitHub 2 ไฟล์

## เตรียมภาพ

- ใช้ไฟล์ PNG, JPG หรือ WebP อย่างน้อย **24 ภาพ** (สูงสุด 60 ภาพ)
- แนะนำภาพสี่เหลี่ยมจัตุรัส ขนาด 300–1000 px ใช้พื้นหลังโปร่งใสหรือสีขาว
- **ตั้งชื่อไฟล์เป็นชื่อตัวละคร** เช่น `น้องหมี.png` ระบบจะดึงชื่อไฟล์มาใช้เป็นชื่อตัวละคร (แก้ทีหลังได้)
- ไม่ต้องย่อภาพเอง ระบบย่อเหลือ 360 px ให้อัตโนมัติ ขนาดรวมทั้งชุดจะอยู่ที่ประมาณ 0.2–1 MB
- ควรใช้ภาพที่คณะหรือนักศึกษาออกแบบเอง หรือภาพที่ได้รับอนุญาต

## สร้างชุดภาพใหม่

1. เปิด `https://<ชื่อบัญชี>.github.io/character-bingo/admin.html` บนคอมพิวเตอร์ (แนะนำ Chrome หรือ Edge)
2. กด **+ สร้างชุดใหม่** ตั้งชื่อ เช่น `Art Toy Open House 2026` แล้วเลือกประเภท (Anime / Art Toy / Cartoon …)
3. **ลากไฟล์ภาพทั้งหมดมาวาง** ในกรอบเส้นประ หรือกด **เลือกไฟล์ภาพ** แล้วเลือกหลายไฟล์พร้อมกัน
4. ระบบจะตรวจให้อัตโนมัติ และแจ้งรายชื่อไฟล์ที่ใช้ไม่ได้ เช่น ไฟล์เสีย ไฟล์ที่ไม่ใช่ภาพ หรือภาพเล็กเกินไป
5. ตรวจกล่องสถานะด้านบน
   - ✅ **พร้อมใช้งาน** = ใช้ได้แล้ว
   - กล่องสีแดง = ยังมีปัญหา เช่น ตัวละครยังไม่ครบ 24 ตัว หรือยังไม่ได้ตั้งชื่อ
   - กล่องสีเหลือง = คำเตือน เช่น ชื่อตัวละครซ้ำกัน
6. แก้ชื่อตัวละครในช่องใต้ภาพ กด **เปลี่ยนภาพ** เพื่อเปลี่ยนเฉพาะภาพนั้น หรือกด **ลบ**
7. กด **ดูตัวอย่างบัตร** เพื่อดูหน้าจอแบบที่ผู้เล่นจะเห็น
8. ถ้าต้องการลองสุ่มก่อนเผยแพร่ ให้กด **ทดลองสุ่มในเครื่องนี้**

งานทุกอย่างจะบันทึกในเบราว์เซอร์เครื่องนี้อัตโนมัติ (ฉบับร่าง) ปิดแล้วกลับมาทำต่อได้

## เผยแพร่ให้ผู้เล่นเห็น (อัปโหลดขึ้น GitHub)

1. ในหน้าจัดการภาพ กด **1) ดาวน์โหลดไฟล์ชุดภาพ** จะได้ไฟล์ `<รหัสชุด>.json`
2. กด **2) ดาวน์โหลด index.json** ถ้าต้องการให้ชุดนี้เป็นชุดเริ่มต้นของเกม ให้ติ๊ก “ตั้งเป็นชุดเริ่มต้น” ไว้
3. เปิดหน้า repository บน GitHub → เข้าโฟลเดอร์ `themes` → **Add file › Upload files**
4. ลากไฟล์ทั้งสองไปวาง (ไฟล์ชื่อเดิมจะถูกแทนที่) → กด **Commit changes**
5. รอ 1–3 นาที แล้วรีเฟรชหน้าพิธีกร ชุดใหม่จะอยู่ในช่อง **ชุดภาพ**

## สลับชุด Theme สำหรับกิจกรรมครั้งต่อไป

- **วิธีที่ 1:** ในหน้าพิธีกร ให้เลือกชุดในช่อง “ชุดภาพ” QR Code จะเปลี่ยนเป็นของชุดนั้นอัตโนมัติ (ลิงก์ลงท้ายด้วย `?t=รหัสชุด`)
- **วิธีที่ 2:** เปลี่ยนชุดเริ่มต้นโดยดาวน์โหลด `index.json` ใหม่ (ติ๊ก “ตั้งเป็นชุดเริ่มต้น”) แล้วอัปโหลดแทนไฟล์เดิม
- ชุดเก่ายังอยู่ในเว็บ สามารถสลับกลับไปใช้ได้ทุกเมื่อ

## แก้ไขชุดที่อยู่บนเว็บแล้ว

1. กด **คัดลอกชุดจากเว็บไซต์มาแก้** แล้วเลือกชุดที่ต้องการ
2. แก้ภาพหรือชื่อ แล้วส่งออกและอัปโหลดตามขั้นตอนข้างบน (ใช้รหัสชุดเดิม ไฟล์บนเว็บจะถูกแทนที่)

## ข้อควรระวัง

| การแก้ไข | บัตรที่เคยพิมพ์ / บัตรในมือถือ |
|---|---|
| เปลี่ยนภาพ หรือเปลี่ยนชื่อตัวละคร | ✅ ใช้ต่อได้ |
| เพิ่ม หรือลบตัวละคร | ❌ บัตรเดิมใช้ไม่ได้ ต้องพิมพ์บัตรสำรองใหม่ |
| เปลี่ยนรหัสชุด | ❌ ระบบจะถือเป็นชุดใหม่ |

- บัตรทุกใบและหน้าพิธีกรจะแสดง **รหัสชุด** (เช่น `J7FC1`) ถ้ารหัสบนบัตรกระดาษตรงกับหน้าพิธีกร แปลว่าบัตรนั้นใช้กับชุดนี้ได้
- อย่าแก้ชุดภาพในวันจัดกิจกรรม
- ควรเก็บไฟล์ `.json` ที่ส่งออกไว้ เพราะใช้ **นำเข้าไฟล์ .json** กลับมาแก้ในเครื่องอื่นได้
