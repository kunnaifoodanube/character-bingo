## สรุป

- **สื่อครบ 32/32 คำ** (ภาพนิ่ง 25 · คลิปวิดีโอ 7) ทุกไฟล์มาจาก **Wikimedia Commons**
- ทุกไฟล์เป็น **สาธารณสมบัติ (Public domain / CC0)** หรือ **Creative Commons ที่อนุญาตให้ใช้ซ้ำ** (CC BY 2.0/3.0, CC BY-SA 3.0/4.0) ตรวจจาก Commons API รายไฟล์ ไม่ได้อาศัยการ “ใส่เครดิต” อย่างเดียว
- **ไม่มีภาพหรือคลิปที่สร้างด้วย AI**
- **ไม่ได้ดาวน์โหลดไฟล์มาเก็บใน GitHub** — เกมแสดงจาก upload.wikimedia.org โดยตรง (ภาพนิ่งถูกเก็บไว้ในเครื่องพิธีกรเพื่อใช้ออฟไลน์)
- ภาพที่ใช้ไม่มีคำศัพท์ของข้อนั้นเขียนอยู่บนภาพ (มีเพียงข้อความประกอบที่เป็นส่วนหนึ่งของงาน เช่น ไตเติลการ์ดของ The Kid “A picture with a smile…” และวันเวลาบนภาพแบบกล้องวิดีโอในข้อ Found Footage)
- เกมจะ **ไม่แสดงสื่อใดที่สถานะสิทธิ์ไม่ใช่ “ตรวจสอบสิทธิ์แล้ว”** (ตั้งได้ในหน้าจัดการภาพ)

## เงื่อนไขการใช้ที่ต้องรักษาไว้

- ภาพ/คลิป CC BY และ CC BY-SA ต้องแสดงชื่อผู้สร้าง ลิงก์ที่มา และลิงก์สัญญาอนุญาต — เกมแสดงไว้แล้วที่ปุ่ม **“ⓘ เครดิตภาพนี้”** (บนจอใหญ่ทุกครั้งที่สุ่ม) และ **“เครดิต / แหล่งภาพ”** (หน้าพิธีกรและหน้าจัดการภาพ)
- เกมแสดงไฟล์ต้นฉบับโดยไม่ดัดแปลง (การย่อให้พอดีกรอบไม่ตัดภาพ) จึงไม่เกิดเงื่อนไข “ShareAlike” สำหรับงานดัดแปลง
- ภาพ PD จากภาพยนตร์ยุคก่อนปี 1931 (สหรัฐฯ) และงานที่เก่ากว่า 50 ปี — พ.ร.บ.ลิขสิทธิ์ไทยคุ้มครองงานภาพยนตร์/โสตทัศนวัสดุ/ภาพถ่าย 50 ปีนับแต่เผยแพร่ครั้งแรก จึงพ้นอายุคุ้มครองแล้ว (ข้อมูลประกอบการตัดสินใจ ไม่ใช่คำปรึกษาทางกฎหมาย)
- ดาวน์โหลดรายการเครดิตทั้งหมดเป็นไฟล์ CSV ได้ที่หน้าจัดการภาพ → ปุ่ม “ส่งออกเครดิต (CSV)”

## วิธีตรวจซ้ำ

- เปิด `tools/media-picker.html?theme=film-animation` บนเว็บไซต์ จะเห็นสื่อจริงทั้ง 32 รายการ พร้อมสรุป “โหลดได้ X / 32”
- เปลี่ยนสื่อของคำใด: หน้าจัดการภาพ → คัดลอกชุดจากเว็บไซต์ → การ์ดคำนั้น → “สื่อ/เครดิต” ใส่ลิงก์ ที่มา สัญญาอนุญาต แล้วเลือก “ตรวจสอบสิทธิ์แล้ว” เท่านั้นจึงจะแสดงบนจอ
