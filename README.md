# Character Bingo

เว็บเกมบิงโกตัวละครสำหรับกิจกรรม Workshop / Open House คณะดิจิทัลมีเดีย
นักเรียนสแกน QR Code แล้วเล่นบนมือถือได้ทันที ไม่ต้องติดตั้งแอปหรือสมัครสมาชิก
ทำงานเป็นเว็บ Static ล้วน: **ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มีค่าใช้จ่าย**

| หน้า | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| ผู้เล่น | `index.html` | รับบัตร 4×4 แตะทำเครื่องหมาย แสดง BINGO |
| พิธีกร | `host.html` | ฉายขึ้นโปรเจกเตอร์ สุ่มตัวละคร แสดง QR ตรวจบัตร เริ่มรอบใหม่ |
| จัดการภาพ | `admin.html` | อัปโหลด / แก้ชื่อ / เปลี่ยน / ลบภาพ สร้างชุด Theme และส่งออก |
| พิมพ์บัตรสำรอง | `print.html` | พิมพ์บัตรกระดาษหรือบันทึกเป็น PDF |

## หลักการทำงาน (สรุป)

1. **บัตรสร้างจากหมายเลข** หมายเลขบัตร + ชุดภาพ จะได้บัตรหน้าตาเดิมทุกครั้งในทุกเครื่อง
   พิธีกรจึงพิมพ์เลขบัตรแล้วสร้างบัตรเดียวกันขึ้นมาตรวจได้ โดยไม่ต้องส่งข้อมูลผ่านเน็ต
2. **เลขบัตร 5 หลัก + เลขตรวจสอบ 1 หลัก** (เช่น `48213-5`) ถ้าพิมพ์ผิดหนึ่งหลักหรือสลับหลัก ระบบจะเตือน
   บัตรกระดาษใช้เลข 00001–09999 ส่วนบัตรมือถือใช้เลข 10000–99999 จึงไม่ชนกัน
3. **ตรวจรางวัลจากประวัติการสุ่มของพิธีกรเท่านั้น** ผู้เล่นแตะผิดหรือแตะเกินก็แจ้งชนะเท็จไม่ได้
4. **Offline**: Service Worker เก็บไฟล์ทั้งหมดหลังเปิดครั้งแรก ส่วนบัตรเก็บใน localStorage ของมือถือ
5. **ระบบซิงก์ (ส่วนเสริม) มี 2 แบบ**
   - **QR ซิงก์:** ใช้ได้ทันที ไม่ต้องใช้อินเทอร์เน็ต ผู้เล่นสแกน QR บนจอพิธีกรด้วยกล้องมือถือ
   - **ซิงก์เรียลไทม์:** ใช้ Firestore แผนฟรี มือถืออัปเดตเอง และแตะได้เฉพาะตัวที่ถูกเรียกแล้ว (ต้องตั้งค่าครั้งเดียวตามคู่มือ)
   - ถ้าระบบซิงก์ล่ม เกมจะกลับไปทำงานแบบเดิมเอง คือผู้เล่นแตะเอง แล้วตรวจรางวัลจากหน้าพิธีกร

## เผยแพร่ฟรีผ่าน GitHub Pages

> GitHub Pages ใช้ฟรีกับ repository แบบ **Public** (ถ้าเป็น Private ต้องใช้แพ็กเกจเสียเงิน)

1. สมัครบัญชีที่ <https://github.com> (ฟรี) แล้วกด **New repository**
   ตั้งชื่อ เช่น `character-bingo` เลือก **Public** แล้วกด **Create repository**
2. ในหน้า repository ที่ว่างอยู่ ให้คลิกลิงก์ **uploading an existing file**
   แตกไฟล์ ZIP ของโปรเจกต์ แล้ว **ลากไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างใน** ไปวาง
   (`index.html` ต้องอยู่ชั้นนอกสุด ห้ามซ้อนอยู่ในโฟลเดอร์ย่อย) แล้วกด **Commit changes**
3. ไปที่ **Settings › Pages** ตรง Source เลือก **Deploy from a branch** → Branch `main` / `/ (root)` → **Save**
4. รอ 1–3 นาที ที่อยู่เว็บจะเป็น `https://<ชื่อบัญชี>.github.io/character-bingo/`
   - หน้าพิธีกร: `…/character-bingo/host.html`
   - หน้าจัดการภาพ: `…/character-bingo/admin.html`
   - QR Code สำหรับผู้เล่นจะสร้างให้อัตโนมัติในหน้าพิธีกร (ปุ่ม **QR เข้าเกม**)

ไฟล์ `.nojekyll` ต้องอัปโหลดไปด้วย (ถ้าลากทั้งโฟลเดอร์จะติดไปเอง)

**ความปลอดภัย:** ทุกคนเปิดหน้า `admin.html` หรือ `host.html` ได้ แต่สิ่งที่ทำในหน้านั้นมีผลเฉพาะเครื่องของคนที่เปิดเท่านั้น
การเปลี่ยนภาพบนเว็บจริงต้องล็อกอิน GitHub ของอาจารย์เพื่ออัปโหลดไฟล์ ส่วนการตรวจรางวัลให้ทำจากเครื่องพิธีกรเครื่องเดียว

## ทดสอบในเครื่อง (สำหรับผู้พัฒนา)

```bash
python3 -m http.server 8000          # เปิด http://localhost:8000
node --test tests/unit.test.js       # ทดสอบตรรกะ
python3 tests/e2e.py <สำเนาโฟลเดอร์เว็บ> <โฟลเดอร์ภาพทดสอบ> <โฟลเดอร์ผลลัพธ์>   # ต้องติดตั้ง playwright
node tools/make-sample-theme.js      # สร้างชุดตัวละครตัวอย่างใหม่
```

ถ้าแก้ไฟล์โค้ด (ไม่ใช่ไฟล์ภาพ) ให้เปลี่ยนค่า `VERSION` ใน `sw.js` เพื่อให้มือถือที่เคยเปิดเว็บดึงโค้ดใหม่

## ส่วนประกอบภายนอก

- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) โดย Kazuhiko Arase (MIT License) อยู่ใน `assets/vendor/qrcode.js`
- [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0) ใช้อ่าน QR ซิงก์ อยู่ใน `assets/vendor/jsqr.js`
- [Firebase JS SDK](https://github.com/firebase/firebase-js-sdk) 11.10 (Apache-2.0) บันเดิลไว้ใน `assets/vendor/firebase.js` และโหลดเฉพาะเมื่อตั้งค่าซิงก์เรียลไทม์แล้ว
- ไม่เรียกใช้ CDN หรือฟอนต์ภายนอก บริการภายนอกที่ใช้มีเพียง Firestore และจะใช้เมื่อตั้งค่าไว้เท่านั้น
- ตัวละครชุดตัวอย่าง “มอนสเตอร์ขนม” วาดขึ้นใหม่ด้วยโค้ด (`tools/make-sample-theme.js`) ไม่มีลิขสิทธิ์ของผู้อื่น
