จัดการภาพตัวละคร

หน้าจอพิธีกร หน้าผู้เล่น
ชุดภาพที่แก้ในหน้านี้จะ บันทึกในเบราว์เซอร์เครื่องนี้ ก่อน (ฉบับร่าง) — เมื่อพร้อมใช้งานจริง ให้กด “ส่งออก” แล้วอัปโหลดไฟล์ขึ้น GitHub ตามขั้นตอนด้านล่าง ผู้เล่นจึงจะเห็นภาพชุดนี้

ชุดภาพ (Theme)

แก้ไขชุด:

แก้คำ/คำแปลได้ในการ์ด · กด “สื่อ/เครดิต” เพื่อใส่ลิงก์ภาพหรือคลิป แหล่งที่มา และสัญญาอนุญาต

ลากไฟล์ภาพมาวางที่นี่ หรือ

รองรับ PNG, JPG, WebP · ระบบย่อภาพให้อัตโนมัติ · ชื่อไฟล์จะใช้เป็นชื่อตัวละคร (แก้ได้)
แนะนำภาพสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใสหรือสีขาว

ตัวละคร

ทดลองสุ่มในเครื่องนี้

ส่งออกเพื่อเผยแพร่ (GitHub Pages)

  1. กดปุ่ม 1 และ 2 จะได้ไฟล์ xxx.json และ index.json
  2. เปิดหน้า repository บน GitHub → เข้าโฟลเดอร์ themes → Add file › Upload files
  3. ลากไฟล์ทั้งสองไปวาง (ไฟล์ชื่อเดิมจะถูกแทนที่) → กด Commit changes
  4. รอ 1–3 นาที แล้วเปิดหน้าพิธีกร ชุดใหม่จะอยู่ในรายการเลือกชุดภาพ

ไม่ต้องแก้โค้ดใด ๆ · ห้ามเพิ่ม/ลบตัวละครหลังพิมพ์บัตรกระดาษแล้ว (บัตรเดิมจะใช้ไม่ได้) แต่เปลี่ยนภาพหรือชื่อได้
